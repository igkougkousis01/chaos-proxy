# Support

Chaos Proxy is a small project maintained in spare time. Everything happens on GitHub.

| You want to                      | Go to                                                                                              |
| -------------------------------- | -------------------------------------------------------------------------------------------------- |
| Report a bug                     | [Issues](https://github.com/igkougkousis01/chaos-proxy/issues) — use the bug report template       |
| Request a feature                | [Issues](https://github.com/igkougkousis01/chaos-proxy/issues) — use the feature request template  |
| Ask a question or get usage help | [Issues](https://github.com/igkougkousis01/chaos-proxy/issues) — GitHub Discussions is not enabled |
| Report a security vulnerability  | [SECURITY.md](SECURITY.md) — not the issue tracker                                                 |
| Contribute a change              | [CONTRIBUTING.md](CONTRIBUTING.md)                                                                 |

Before opening an issue, these usually answer it faster:

- [README](README.md) — every flag, the config file format, and what each kind of chaos does.
- `chaos-proxy --help` — the whole command line on one screen.
- `chaos-proxy --print-config` — what a run would actually do, without starting anything. Most
  "why is nothing happening" questions are answered here.
- [docs/project-overview.md](docs/project-overview.md) — what is deliberately out of scope.
